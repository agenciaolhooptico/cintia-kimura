# Dra. Cíntia Kimura

Site institucional estático em português, com layout responsivo, procedimentos em carrossel e contato pelo WhatsApp.

## Desenvolvimento

Requer Node.js 18 ou mais recente. Não há dependências de instalação.

```sh
npm run check
npm run build
```

`src/` contém o gerador, o CSS e o carrossel. `public/` contém as fotos e os arquivos estáticos. O build gera `docs/`, usado pelo GitHub Pages.

## Publicação

GitHub Pages: branch `main`, pasta `/docs`. Após alterações, execute o build e envie os fontes e `docs/` no mesmo commit.

URL: https://agenciaolhooptico.github.io/cintia-kimura/
